# 📚 PulseConnect Project Documentation

Welcome to the documentation repository for the **PulseConnect (Blood Donor Connect)** platform.

## 📑 Available Documentation

- **[Software Requirements Specification (SRS)](./SRS_DOCUMENT.md)**: Formal IEEE 830 / ISO/IEC/IEEE 29148 compliant software specification document detailing functional requirements (FR-01 to FR-12), non-functional requirements (NFRs), system architecture, ER diagrams, data flow diagrams (DFD), and mathematical algorithms (Haversine & Blood Compatibility Matrix).
- **[List of Things Used in this Project](./LIST_OF_THINGS_USED.md)**: A complete, itemized inventory of all programming languages, frontend/backend frameworks, UI libraries, database systems, third-party APIs, algorithms, datasets, design systems, and developer tools used across PulseConnect.

## 🏥 About PulseConnect
PulseConnect is a hyper-local, privacy-centric emergency blood donor matching and SOS broadcasting platform built to bridge the gap between critical blood requirements and verified voluntary blood donors across India.
